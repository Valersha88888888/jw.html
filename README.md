J&W Quality Hemservice

Professionell städservice i Stockholm med fokus på kvalitet, noggrannhet och pålitlighet.

Denna webbplats är företagets officiella digitala plattform och presenterar våra tjänster samt möjliggör direktkontakt med kunder via integrerat kontakt- och omdömesformulär.

🌐 Live webbplats:  
https://jwquality.se



 Om företaget

J&W Quality Hemservice erbjuder professionella städtjänster för både privatpersoner och företag i Stockholm med omnejd.

Vårt mål är att leverera högsta kvalitet i varje uppdrag. Vi arbetar noggrant, effektivt och med stor respekt för kundens hem eller arbetsplats.

Vi tror på:
- Kvalitet framför kvantitet
- Tydlig kommunikation
- Punktlighet
- Långsiktiga kundrelationer



Våra tjänster

- Hemstädning
- Flyttstädning
- Storstädning
- Fönsterputs
- Kontorsstädning
- Företagsstädning

Alla tjänster anpassas efter kundens behov.



 Webbplatsens funktioner

Webbplatsen är utvecklad för att vara:

- Responsiv (mobil, surfplatta och desktop)
- Snabb och optimerad
- SEO-anpassad
- Enkel att navigera

Funktioner inkluderar:

- Dynamisk hero-sektion med typewriter-effekt
- Kontaktformulär med EmailJS-integration
- Omdömesformulär (review system)
- Automatisk hantering av e-postförfrågningar
- Responsiv meny (burger menu)
- Säker publicering via GitHub



Teknisk implementation

Projektet är byggt med:

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- EmailJS (formulärhantering)
- GitHub för versionshantering
- Anpassad domän (CNAME)

 EmailJS Integration

Kontakt- och omdömesformulären är kopplade till EmailJS, vilket möjliggör:

- Direkt e-postleverans
- Ingen backend-server krävs
- Säker och snabb hantering av kundförfrågningar
